# Setup and Run Instructions

## 1. Install Dependencies
```bash
npm install
```

## 2. Install Tailwind CSS (if not already installed)
```bash
npm install -D tailwindcss postcss autoprefixer
```

## 3. Run the Application

### Development Mode (Recommended)
```bash
npm run dev
```
This will start the frontend at `http://localhost:5173`

### Start Backend Server (in another terminal)
```bash
npm run server
```
This will start the backend at `http://localhost:3000`

## 4. Access Your Application
- Open `http://localhost:5173` in your browser
- You'll see the modern UI matching https://textbook-quality-hub.lovable.app/

## 5. Test the Features
- **Home Page**: Browse textbooks and reviews
- **Sign Up**: Create accounts for different roles (admin, reviewer, publisher, student)
- **Sign In**: Login with your credentials
- **Dashboards**: Access role-based dashboards
